# CouchSplit 0.2.0 Alpha 9 — GBA split screen and experimental FireRed co-op

Alpha 9 brings the GBA work into the downloadable launcher. Two players can run
independent GBA games in one window, or opt into shared battles and reviewed
story synchronization with the **exact unmodified German FireRed original**.
Project PM / Pokémon Platinum and the English/German interface remain available.
No game, save or proprietary BIOS is included, and the FireRed ROM file is unchanged.

## FireRed changes

- Enable **Settings → FireRed co-op (experimental)** for the next session. The
  launcher identifies a supported ROM and shows battle ownership and partner waits.
- See the partner on the same map and directly connected outdoor maps. Shared
  battles require both players to be ready on the same map.
- Use each player's own six-Pokémon switch menu. Participation and EXP Share
  awards are tracked across all twelve owned slots. The original engine performs
  EXP/EV awards, move learning and evolutions with the correct player's input and
  National Dex eligibility.
- Refresh reviewed campaign changes without leaving the loaded map, including
  Seafoam water-current layouts and Pokémon Center upper floors, while preserving
  personal puzzle and event data.
- Select player-one, player-two, mixed or muted audio. Create and restore verified
  paired backups of the two latest in-game saves.
- A held Enigma Berry pauses the session with an explicit **Continue individual
  battles** action. EXP Share capacity no longer causes this admission pause.

## Verification and limits

Linux checks use the original ROM, private authored checkpoints and virtual SDL
controllers. They cover twelve EXP Share recipients, twelve pending evolutions,
full-party switching, differing National Dex eligibility, native saves/fresh
Continue and 32 targeted map cases. A sustained test drives the production
Session/PlayView and paired worker through repeated native encounters, map
transitions and saves. The [dated verification record](https://github.com/Philmenting/couchsplit/blob/main/docs/verification/firered-alpha9-2026-11-08.json)
contains the completed results and exact scope. The sustained run passed ten
cycles in 19 minutes 17 seconds: ten shared battles, twenty map transitions,
43 native saves per player during the session and one more after fresh Continue.
No continuous campaign is claimed.

FireRed remains **experimental**. Partner collision/terrain occlusion, remaining
special map/battle modes, Shedinja party addition and per-owner Pokérus spreading
are incomplete. Active, queued and Wish references can still exhaust the native
working party and require rollback. Multi-hour play, physical controllers,
audible output and Pokémon gameplay on Windows/Bazzite remain unverified.
[Setup and known limits](https://github.com/Philmenting/couchsplit/blob/main/docs/firered.md).

Publication requires native Linux/Windows builds, component/UI/controller/session
checks, package installation/upgrades and ARM regression checks. These CI checks
are separate from original-ROM gameplay and target-hardware acceptance.

## Downloads and updating

- `CouchSplit-Windows-Setup.exe` — per-user Windows x64 installer.
- `CouchSplit-Windows-Portable.zip` — extract fully, then use `Start.bat`.
- `CouchSplit-ZorinOS18-amd64.deb` — Zorin OS 18 / Ubuntu 24.04 x86_64.
- `CouchSplit-Bazzite.run` — Bazzite x86_64 installer with its own runtime.
- `Pokemon-PM-ROM-Korrekturen.zip` — existing fingerprint-checked Project PM
  correction tools; no game included.
- `SHA256SUMS` — checksums for all five packages.

Install over the previous version. Existing profile directories, application IDs,
settings, ROMs and saves retain their locations. Each player and ROM fingerprint
has separate saves; no automatic save merging occurs. Packages include matching
project and pinned emulator source/licenses. Earlier releases remain unchanged.

## Deutsch

Alpha 9 enthält **GBA-Splitscreen und experimentellen deutschen Feuerrot-Koop**.
Mit der exakten unveränderten Original-ROM lässt sich der Modus unter
**Einstellungen → Feuerrot-Koop (experimentell)** einschalten. Eigene Sechserteams,
EP/EV für bis zu zwölf Pokémon, besitzerabhängiges Lernen/Entwickeln und weitere
native Kartenaktualisierungen sind enthalten. Die ROM-Datei wird nicht verändert.

Die Tests prüfen gezielte Originalszenarien und wiederholte Kämpfe, Kartenwechsel
und Saves in einer laufenden Launcher-Sitzung. Ein vollständiger Kampagnendurchlauf,
echte Controller und Pokémon-Spielabnahme auf Windows/Bazzite stehen aus.
Spezialfälle bleiben offen; der Modus ist weiterhin experimentell.
[Deutsche Anleitung und Grenzen](https://github.com/Philmenting/couchsplit/blob/main/docs/de/firered.md).
Bestehende Einstellungen und Spielstände bleiben bei der Aktualisierung erhalten.
