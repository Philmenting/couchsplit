# CouchSplit 0.2.0 Alpha 12

English FireRed 1.0 and 1.1 join the experimental co-op mode. Both players keep
their own teams, bags and saves, see their partner in the world, and choose
their own actions in shared native battles.

The launcher and paired worker select a separate ABI profile using the complete
cartridge fingerprint. Native callback/data locations, all 38 battle hooks,
caller guards, language-specific battle text and Hall-of-Fame pointers follow
that profile. The reserved-team-slot explanation now follows the game language.
Unknown or modified cartridges remain outside FireRed co-op.

The supported German original, Project PM / Platinum and ordinary independent
GBA sessions remain available. English cartridges have their own hash-based
save profiles. [Exact supported files and setup](../firered-english-profiles.md).

Windows packaging now includes SDL3 when MSYS2 supplies SDL2 through its
compatibility layer. This dynamically loaded dependency is invisible to the PE
import scan. The existing check still starts the deployed worker and launcher
without MSYS2 in PATH; its timeout and failure checks are retained.

Forty targeted actual-ROM scenarios passed: 18 on each English revision and
four German regressions. Each includes separate native SAVE and fresh
battery-only Continue for both players. Coverage includes both battle
initiators, catches and acting trainer names, full own-team menus, twelve EXP
Share recipients, native learning/evolutions, Wish names after source eviction,
Roar/Whirlwind, action counters, legendary encounters, escape and defeat.
[Verification record](../verification/firered-english-2026-11-10.json).

Release gates include native Windows/Linux builds and component tests, the
Python suite, isolated Windows deployment checks, and installer upgrades. They
are separate from actual Windows/Bazzite Pokémon gameplay.

FireRed remains experimental. These are authored test scenarios and virtual
input, with no continuous campaign or physical-controller certification.
Partner collision/occlusion and special modes retain their existing limits.
No ROMs, BIOS, firmware, saves or checkpoints are included. Alpha 11 and all
previously published assets remain unchanged.
