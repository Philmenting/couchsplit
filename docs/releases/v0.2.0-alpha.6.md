# 0.2.0 Alpha 6 — Retro launcher & co-op battle corrections

The tested launcher improvements and separate ROM correction tools, together in a public release for Windows, Zorin OS 18 / Ubuntu 24.04 and Bazzite. No Nintendo ROMs, BIOS, proprietary firmware or user saves. All packages remain alpha releases; the launcher interface is German.

## Changes since the public Alpha 1 release

- Native handheld-inspired menu with an OFL pixel font, a clear start action, visible focus and layouts from small windows to 4K.
- Stable `game.sav` names per player/ROM hash, backed-up migration of unambiguous legacy filenames and verified backup restoration.
- Correct controller ownership during assignment, disconnection and reconnection. Neutral game input when hidden, minimized or in the launcher menu.
- ROM changes are blocked during a session; the launcher and both workers stop cleanly.
- Separate ROM target correction: select an available target after an opponent faints.
- Separate ROM item correction: prevent the extra one-sided HP barrier after a partner's Potion, preserving native healing.
- Updated repository front page with real launcher/co-op captures, setup instructions and evidence-based test status.

## Setup and updates

Update the launcher and emulator together. Select your own compatible Project-PM-patched ROM and assign two controllers. PM 0.4.5 unlocks Wireless Play after the Pokédex; shared trainer battles require the in-game co-op setting.

ROM corrections are **not applied automatically**. The tools accept only the exact documented fingerprints and create new files. A new ROM hash gets separate save directories; existing progress stays in its previous profile. Back up both players' saves before switching. [Explicit save transfer](https://github.com/Philmenting/couchsplit/blob/v0.2.0-alpha.6/docs/save-transfer.md).

## Verification and limits

Publication requires native Linux/Windows builds, CTest, real-emulator smoke tests, package/installation checks and ARM regression tests. ROM-free smoke tests use our own homebrew. The local complete Python suite uses real xdelta and ARM dependencies; the dedicated ARM matrix must not skip tests.

Actual Pokémon co-op checks were performed on Linux using virtual SDL controllers: shared world views and movement, wild/trainer battles, independent commands and both ROM corrections. Targeted healing/victory cases use separate copied saves with a prepared level-25 team; wallet, inventory, story and trainer flags were not edited during preparation. In the tested shared victory over Sven, each player receives 96 ₽; balances and victory flags survive normal saving and restarting.

Physical controllers, actual Windows/Bazzite Pokémon gameplay, KDE Wayland/Gamescope on target hardware, trading, a complete German playthrough and long sessions remain separate acceptance tests.
