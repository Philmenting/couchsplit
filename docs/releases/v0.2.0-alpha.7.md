# 0.2.0 Alpha 7 — English & German launcher

Choose **English** or **Deutsch** when starting the launcher for the first time. Existing installations without a saved language receive the same choice once, before ROM setup. The launcher remembers your selection; canceling leaves preferences unchanged.

Change it later under **Settings → Language / Einstellungen → Sprache**. Menus, setup dialogs, play help and the launcher's own validation/errors switch immediately. A running co-op session continues without restarting its workers. Compact settings windows now scroll their fields so wrapped guidance stays readable and OK/Cancel remain available.

The selection changes the launcher only. It does not translate the Pokémon ROM, change its fingerprint, move saves or alter controller ownership. Native file pickers may follow the OS language; raw emulator/OS logs remain as produced.

## Packages

- Windows x64: per-user installer or portable ZIP.
- Zorin OS 18 / Ubuntu 24.04 x86_64: native Debian package.
- Bazzite x86_64: `.run` installer with its own Distrobox runtime.
- `Pokemon-PM-ROM-Korrekturen.zip`: existing authored, fingerprint-checked ROM correction tools; no game included.
- `SHA256SUMS`: checksums for all five packages.

Launcher and emulator packages are rebuilt from the release commit. Publication requires native Linux/Windows builds, UI/controller/session regressions, two real homebrew emulator processes, package/install checks and mandatory ARM checks. New language tests cover persistence, cancellation, legacy fields, corrupt settings, write failures, live switching and DE/EN menu/help fit from 640×360 to 4K.

No new commercial-ROM battle or target-hardware validation is claimed for this language update. Earlier Linux Pokémon tests and their limitations remain documented in [the README](../../README.md). No ROM, Nintendo BIOS, proprietary firmware or user save is distributed. Older releases remain available.

## Deutsch

Beim ersten Start zwischen **Deutsch und Englisch** wählen; die Auswahl wird gespeichert. Später unter **Einstellungen → Sprache** sofort umschalten, auch während einer laufenden Sitzung. Das Einstellungsfenster scrollt bei wenig Platz und zeigt Hinweise vollständig an. Abbrechen speichert keine Sprachwahl; bestehende Profile bleiben erhalten. Spiel-ROM und ihre Sprache werden nicht verändert. Alle Plattformpakete werden passend neu gebaut und erst nach den CI-Prüfungen veröffentlicht.
