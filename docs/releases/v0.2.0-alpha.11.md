# CouchSplit 0.2.0 Alpha 11 — safer FireRed team battles

Alpha 11 brings the latest **experimental German FireRed co-op corrections** into
the Windows, Bazzite and Zorin OS / Ubuntu download packages. Forced switches keep
Pokémon with their owner, and EXP awards remain safe through move learning and
evolution. The original ROM file stays unchanged. Project PM / Platinum,
independent GBA split screen and the English/German launcher remain available.

## Changes since Alpha 10

- **Owned forced switches.** In trainer battles, Roar and Whirlwind select from
  the target player's original party, including reserves outside the current
  battle working party. Without an eligible own reserve, the move follows its
  native failure path. Native randomness, level checks and switch effects remain.
- **Safe EXP awards across both full teams.** Temporary recipient slots are
  restored after each complete native award. Both active Pokémon stay resident
  during level-up and move-learning screens, preserving each player's Pokémon,
  inputs, learned moves and pending evolutions.
- **Wish no longer unnecessarily holds its source slot.** A successful cast
  retains the original caster's name separately, so a fainted caster can be
  replaced while the later announcement and native healing remain correct.
  Unknown or inconsistent references remain protected or fail safely.

## Verification and remaining limits

The [focused verification record](https://github.com/Philmenting/couchsplit/blob/8eb9ad16c1c2cfba0232d1d4ec797ca04da10455/docs/verification/firered-reserves-2026-11-08.json)
was produced before packaging on runtime commit `8eb9ad1`. It records **11 targeted
original-ROM scenarios, 24 component tests and 64 Python tests**, with no skipped
tests. Both players' saves passed native SAVE and fresh Continue. Cases include
both battle initiators, native Wish/Roar/Whirlwind, move learning and evolution.
Parties and prerequisites were prepared; saturated EXP references were explicitly
authored. These checks do not establish a continuous natural campaign.

Alpha 11 packages the same runtime code. The release changes version metadata and
documentation; it does not claim another ROM campaign or sustained run. Publication
requires fresh native Linux/Windows builds, component/UI/session checks,
installation/upgrades and ARM checks. Packages include matching project and pinned
emulator source and licenses, with no ROMs, saves or private checkpoints.

FireRed remains **experimental**. Enigma Berries require the explicit individual
battle option. Remaining special modes/map helpers, partner collision/occlusion,
multi-hour play, physical controllers and audible output remain outside the
verified scope. **The Bazzite practical test with two real controllers is still
pending.** Native build/package CI does not establish Pokémon gameplay on Bazzite
or Windows. [Setup and limits](https://github.com/Philmenting/couchsplit/blob/main/docs/firered.md).

## Downloads and updating

- `CouchSplit-Windows-Setup.exe` — per-user Windows x64 installer.
- `CouchSplit-Windows-Portable.zip` — extract fully, then open `Start.bat`.
- `CouchSplit-ZorinOS18-amd64.deb` — Zorin OS 18 / Ubuntu 24.04 x86_64.
- `CouchSplit-Bazzite.run` — Bazzite x86_64 installer with its own runtime.
- `Pokemon-PM-ROM-Korrekturen.zip` — fingerprint-checked Project PM correction
  tools, with no game included.
- `SHA256SUMS` — checksums for all five packages.

Finish the current session, then install over the previous version. Existing
settings, ROMs and separate player saves keep their established locations and
installer identity. For FireRed, select the supported unmodified German ROM and
enable **Settings → FireRed co-op (experimental)**. Earlier releases remain available.
