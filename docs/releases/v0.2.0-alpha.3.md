Fehlerkorrekturen für Bazzite, ZorinOS 18 / Ubuntu 24.04 und Windows 10/11 x64, zusätzlich zu den Korrekturen aus Alpha 2.

- Ein minimiertes oder verborgenes Hauptmenü führt keine Controller-Aktionen mehr aus. Beim Zurückkehren muss eine gehaltene Taste erst losgelassen werden; dadurch startet eine Sitzung nicht versehentlich im Hintergrund oder direkt beim Wiederherstellen des Fensters.
- Eine ROM-Auswahl während einer laufenden Sitzung wird vor dem Dateidialog mit einem verständlichen Hinweis blockiert. Im Spiel zunächst Start + Select zwei Sekunden gedrückt halten, danach die neue ROM auswählen. Anzeige, Einstellungen und laufendes Spiel können so nicht auseinanderlaufen.
- Die Kombinationen für Ansichtswechsel und Sitzungsende verbrauchen ihre physischen Controller-Tasten vor der frei gewählten DS-Belegung. Dadurch werden auch bei geänderter Belegung keine zusätzlichen Spieltasten durchgereicht. Unbeteiligte Tasten und Spieler bleiben unabhängig.

Neue native Regressionen laufen im Linux- und Windows-Build. Linux-Aktivtests verwenden außerdem zwei echte Emulatoren, selbst erzeugte ARM-Test-ROMs und virtuelle SDL-Controller. Sie prüfen die drei Fehlerfälle, den regulären ROM-Wechsel nach Sitzungsende, Controller-Trennung, Minimieren im Spiel, Prozessausfall und zwölf vollständige Starts/Beendigungen mit getrennten Test-Spielständen.

Launcher und Emulator gemeinsam aus dem Paket aktualisieren. IPC bleibt ABI 2 mit STABLE_SAVE=1. Native Builds, Paketprüfung und Installieren/Deinstallieren sind vor einer Veröffentlichung erforderlich. Physische Controller, Bazzite-/Wayland-/Gamescope-Bedienung und die gemeinsame Sinnoh-Welt bleiben separate manuelle Abnahmen.

Keine ROMs, Nintendo-BIOS oder Firmware enthalten. GPL-3.0-or-later; passende eigene und gepatchte Emulatorquellen liegen den Paketen bei. Bestehende Releases werden nicht überschrieben.
