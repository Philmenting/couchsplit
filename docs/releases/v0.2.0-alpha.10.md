# CouchSplit 0.2.0 Alpha 10 — safer switches and owned evolution results

Alpha 10 improves the experimental **German FireRed couch co-op** in the launcher.
Protected reserve choices stay in the game menu, and native Nincada evolution can
add Shedinja to the correct player's party. The original ROM file stays unchanged.
Project PM / Platinum, independent GBA split screen and the English/German launcher
remain available on Windows and Linux.

## Changes

- **Keep playing after a blocked reserve selection.** A German in-game message
  explains that a slot is temporarily reserved. The owner stays in the same menu
  and can choose an available resident Pokémon, or cancel where the native request
  allows it. Active, queued and Wish references remain protected.
- **Keep Shedinja with its owner.** Native Nincada evolution uses that player's
  full party, capacity, input and National Dex eligibility. A free slot receives
  the native Shedinja and its owned Pokédex receipt. Full parties and canceled
  evolutions create no extra Pokémon. Ninjask/Shedinja retain their authentic shared
  personality/trainer identifiers and remain distinct during later team handling.
- **Preserve Pokérus correctly.** Active and cured status stays with each Pokémon;
  the original engine awards its EV bonus, including unloaded EXP Share holders.
  Correction to an earlier limitation: original FireRed disables random infection,
  spreading and the day countdown. Alpha 10 does not add mechanics from other games.

## Verification and remaining limits

The [dated Alpha 10 verification record](https://github.com/Philmenting/couchsplit/blob/main/docs/verification/firered-alpha10-2026-11-08.json)
describes focused checks with the exact original ROM, two actual emulator cores,
authored private parties/checkpoints, native input and in-game SAVE/fresh Continue.
All **19 native scenarios, 23 component suites and 64 Python tests** pass; the
Python run has no skips. The record distinguishes these checks from production
launcher session/recovery checks. No ROM, save or private checkpoint is distributed.

The [Alpha 9 sustained run](https://github.com/Philmenting/couchsplit/blob/main/docs/verification/firered-alpha9-2026-11-08.json)
remains historical evidence; its ten cycles were not repeated for this release.
FireRed is still **experimental**. Fully pinned forced replacements or EXP paging
can still roll back the whole battle. Enigma Berries require explicit individual
battle recovery. A complete natural campaign, remaining special modes/map helpers,
partner collision/occlusion, multi-hour play, physical controllers and audible
output remain outside the verified scope. **The user's Bazzite practical test is
pending**; native package/build CI does not establish Pokémon gameplay on Bazzite
or Windows. [Setup and limits](https://github.com/Philmenting/couchsplit/blob/main/docs/firered.md).

Release publication waits for native Linux/Windows builds, component/UI/session
checks, package installation/upgrades and ARM checks. Local heavy checks run
sequentially with a 70% single-core CPU quota.

## Downloads and updating

- `CouchSplit-Windows-Setup.exe` — per-user Windows x64 installer.
- `CouchSplit-Windows-Portable.zip` — extract fully, then open `Start.bat`.
- `CouchSplit-ZorinOS18-amd64.deb` — Zorin OS 18 / Ubuntu 24.04 x86_64.
- `CouchSplit-Bazzite.run` — Bazzite x86_64 installer with its own runtime.
- `Pokemon-PM-ROM-Korrekturen.zip` — fingerprint-checked Project PM correction
  tools, with no game included.
- `SHA256SUMS` — checksums for all five packages.

Install over the previous version. Application/profile locations and installer
identity stay the same; existing settings, ROMs and separate player saves remain
in place. Packages include matching project and pinned emulator source/licenses.
Earlier releases remain available.

## Deutsch

Alpha 10 verbessert den **experimentellen deutschen Feuerrot-Koop**: Eine gesperrte
Reserveauswahl bleibt mit Hinweis im Spielmenü. Ninjatom aus Nincadas Entwicklung
landet im freien Teamplatz des richtigen Besitzers, samt Pokédex-Eintrag; Abbruch
und volle Teams werden berücksichtigt. Ninjask/Ninjatom bleiben trotz gemeinsamer
Originalkennung getrennt zugeordnet. Eigener Pokérus-Status und nativer EV-Bonus
bleiben erhalten. Die frühere Vermutung einer gemischten Pokérus-Verbreitung war
falsch: Diese Mechanik ist im originalen Feuerrot deaktiviert.

Die ROM-Datei wird nicht verändert. Gezielte Originalszenarien mit Speichern und
Neustart sind vom vollständigen Kampagnen- und Hardwaretest zu unterscheiden.
Der Bazzite-Praxistest mit echten Controllern steht noch aus; der Modus bleibt
experimentell. Vorhandene Einstellungen und Spielstände bleiben beim Update
in ihren bisherigen Verzeichnissen.
[Deutsche Anleitung](https://github.com/Philmenting/couchsplit/blob/main/docs/de/firered.md).
