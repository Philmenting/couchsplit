# CouchSplit 0.2.0 Alpha 8 — Couch co-op & split screen

**Pokémon Platinum Local Co-op is now CouchSplit.** The new name puts local play and a shared screen first. Current game support remains **Project PM / Pokémon Platinum**; this update does not add support for other games.

The launcher, window/dialog titles, application-menu shortcuts, installers and current package filenames use CouchSplit. English/German language selection, controller ownership, screen layouts and independent saves keep working as before.

## Updating

Install the new package over the previous version. The existing profile directories, application IDs, Debian package ID, Windows installer identity/default folder and Bazzite runtime ownership are retained so updates find the same settings, ROMs and saves. No save migration or ROM modification is performed. On Windows, the installer replaces the known old named application shortcuts with CouchSplit shortcuts. Existing Steam entries can still show their previous name; the launcher does not rewrite Steam configuration.

## Downloads

- `CouchSplit-Windows-Setup.exe` — per-user Windows x64 installer.
- `CouchSplit-Windows-Portable.zip` — extract fully, then use `Start.bat`.
- `CouchSplit-ZorinOS18-amd64.deb` — Zorin OS 18 / Ubuntu 24.04 x86_64.
- `CouchSplit-Bazzite.run` — Bazzite x86_64 installer with its own runtime.
- `Pokemon-PM-ROM-Korrekturen.zip` — existing fingerprint-checked correction tools for the verified ROM; no game included.
- `SHA256SUMS` — checksums for all five packages.

Publication requires native Linux/Windows builds, UI/controller/session and package/install checks, two real homebrew emulator processes and ARM regression checks. No new Pokémon gameplay or physical target-hardware validation is claimed for this naming update. All packages include matching GPL source. Previous releases remain available.
