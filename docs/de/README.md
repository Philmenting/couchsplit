# CouchSplit-Anleitungen

[English](../README.md) · **Deutsch** · [Projektübersicht](../../README.md#deutsch)

In Alpha 12 unterstützt: **Project PM / Pokémon Platin**, **GBA-Spiele und ROM-Hacks mit getrennten Sitzungen** und ein **aktivierbarer englischer/deutscher Feuerrot-Koop-Testmodus** mit Profilen für die exakten englischen Originale 1.0/1.1 und die deutsche Ausgabe. Alpha 8 bleibt als ältere reine Platin-Version verfügbar. Die Launcher-Sprache verändert die Spiel-ROM nicht. Befehle werden, soweit nicht anders angegeben, im Projektverzeichnis ausgeführt. Historische Berichte behalten ihr Datum und ihre Prüfgrenzen.
